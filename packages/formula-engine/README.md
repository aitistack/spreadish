# `@spreadish/formula-engine`

Lexer, parser, AST, and evaluator for Spreadish formulas. No `eval` / `new Function`.

```bash
bun add @spreadish/formula-engine
```

Docs: [https://spreadish.aitistack.com/docs/api/formula-engine](https://spreadish.aitistack.com/docs/api/formula-engine)
