# `@spreadish/react`

Virtualized React spreadsheet grid for Spreadish.

```bash
bun add @spreadish/react
```

Import styles once in your app entry:

```ts
import '@spreadish/react/styles.css';
```

Docs: [https://spreadish.aitistack.com/docs/api/react](https://spreadish.aitistack.com/docs/api/react)

Peer dependencies: `react`, `react-dom` (^19).
