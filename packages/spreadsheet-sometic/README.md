# `@spreadish/sometic`

Official Sometic persistence and multi-workbook workspace adapters for Spreadish.

```bash
bun add @spreadish/sometic
```

Docs: [https://spreadish.aitistack.com/docs/api/sometic](https://spreadish.aitistack.com/docs/api/sometic)

Peer dependencies: `@sometic/core`, `@sometic/query`, `@sometic/store`.
